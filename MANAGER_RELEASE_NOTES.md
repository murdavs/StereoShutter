# StereoShutter Manager 0.1.120

[Download Manager](https://github.com/murdavs/StereoShutter/releases/latest/download/StereoShutterManager.zip) · [Release assets](https://github.com/murdavs/StereoShutter/releases/latest)

Manager is a free Windows 10/11 x64 application for finding installed games, managing compatible
stereoscopic fixes, configuring supported 3D outputs and opening StereoShutter Player and Photos.
It is supplied in its own ZIP, alongside standalone StereoShutter 0.18.111.209.

## What changed in 0.1.120

- Fixed an installation error when adding StereoShutter to a game.
- Improved verification when installing compatible HelixMod fixes.

## Previous release: 0.1.119

- Hide games from your library, add search folders and browse the available fixes.
- Improved fix detection, downloads and preservation of your settings during updates.
- Fixed configuration saving when adding StereoShutter.
- Improved retrieval of missing Steam artwork.
- Guided troubleshooting: enable diagnostics, reproduce an issue and prepare a report to share by email, ZIP or Discord.

## Previous release: 0.1.116

- **Clearer game-fix release notes:** concise changes shown in the selected interface language,
  with seven translations instead of duplicated languages in one view.
- **Reviewed Witcher 3 instructions:** clean English and Spanish author guidance for the exact
  published The Witcher 3 DX12 fix 0.1.4.
- **More readable presentation:** improved layout for those notes and instructions,
  focusing on the player’s setup and the changes they need to know.

These are Manager display and documentation improvements. They do not change the game’s shaders,
Engine DLL or fix archive. Each game fix has its own version and release notes.

## Getting started

1. Extract the ZIP to a writable folder and keep its files together.
2. Run `StereoShutterManager.exe`, find the installed game and read the fix’s instructions.
3. Install a compatible fix with the game closed, then choose the 3D output.
4. For shutter glasses, complete and save calibration before playing.

Components and game fixes download when requested. The application ZIP does not include games,
a collection of fixes or a universal Engine. Public fixes and general configuration do not require
sign-in; eligible early-access content uses the account system.

See [the project overview](README.md) and `docs/USER_GUIDE.md` inside the Manager ZIP.
The package also includes privacy information. The executable is unsigned; use the official release
and its published SHA-256 when checking the download.
