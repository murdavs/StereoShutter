# Changes

## StereoShutter 0.18.83 — first public release — 2026-10-11

One download, three folders: **StereoShutter 0.18.83** (with StereoShutter_host.dll 0.18.29, StereoShutter_Feedback 0.18.77 and the tools), **StereoShutter Player 1.0.2** and **StereoShutter Photos 1.0.2**. The full text is in the [release notes](RELEASE_NOTES.md).

- 📷 **StereoShutter Photos 1.0.2**: 3D photos (MPO, JPS, PNS, side-by-side and top/bottom pictures) through the glasses, a whole folder or a slideshow, full screen or in a window.
- 🎬 **StereoShutter Player 1.0.2**: Blu-ray 3D playback from the film's start, with timeline, seeking and external subtitles synchronized to the 3D pictures; error handling for damaged media and subtitle pictures.
- 📖 **Illustrated manuals** in English and Spanish for the three programs.
- 🩺 **StereoShutter_Feedback 0.18.77**: Windows 10-compatible report dialogs and one-session capture in a ZIP of at most 5 MB. The user reviews and sends the report by e-mail; there is no automatic sending.
- 🎯 **Supplied settings with the automatic modes on**: output margin (`queue = auto`), GPU priority (`gpu_priority_absolute = auto`) and, for a game that fills the graphics card, a part of it kept for StereoShutter's images (`engine = auto`); 60 cycles a second at 360 Hz, the steadier (90 with `refreshes_per_eye = 2`). Reports off.
- 🎮 **Over a game**: StereoShutter waits for the game's picture and for the window the game really draws in, and follows the game when it makes a new window.
- 🧩 **geo-11 setup**: exclusive full screen and the 3D Vision profile of fixes made for 3D Vision turned off, geo-11's library loading kept for the games that need it, and a fault of two known geo-11 versions fixed, all with undo.
- ⌨️ **Keys**: a key without Alt (Ctrl+T) is taken only while the game or StereoShutter is in front.
- 🎮 **StereoShutter_Play**: the game launcher with a game-controller icon.

For games, install the compatible game-specific 3D fix from [HelixMod](https://helixmod.blogspot.com/search/label/geo-11) first, then connect StereoShutter. The game fixes are separate downloads, not included in this package.
